- Domain層は純粋関数のみ。`Date.now()` を直接呼ばず、`now` を引数で受ける（Store の `now?` 省略時だけ `Date.now()`）。
- 設計書 §4.3 の振る舞いルール（最大剰余法の丸め・終業目安・各種 DomainError 条件）をテストで固定する。日またぎ・休憩60分未満/超・補正・月曜始まりの週は必ずテストする。

- Sonnet B は `src/ui/dev/fakeStore.ts` で並行開発中。AppStore の振る舞いが契約から外れると統合で壊れるので、契約に疑問があれば起票する。
