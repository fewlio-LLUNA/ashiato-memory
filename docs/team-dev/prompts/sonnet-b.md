## 実装の要点
- 日付・時刻の計算は UI で書かず、`withClockTime`・`calendarWeeks` など `src/domain/*` の関数を使う。
- Store の操作が投げる `DomainError` は既存の `useActionRunner` で message をそのまま表示する。
- 却下された入力は表示をストアの値に戻す／日付移動で入力・編集状態を持ち越さない（初版 B3 の差し戻しと同じ方針）。
